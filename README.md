# Python Retro Arcade Games

A collection of classic 2D retro arcade games built with Python and Pygame.

## 🕹️ Games Included
- **Space Invaders**: Classic alien shooter with player defense and enemy waves
- **Commando Shooter**: 2D military action game
- **Racing Game**: Top-down track racer with collision detection
- **Tic-Tac-Toe**: Turn-based strategy game

## 🚀 Running a Game
```bash
python <game_name>.py
```
